# Brand and Media Assets

This directory contains visual brand assets, logos, screenshots, and product diagrams for IntelliSphere.

## Folder Structure

- `/logos/` - Main product logos, icon marks, and wordmarks.
- `/diagrams/` - Software architecture, flowcharts, and system diagrams.
- `/screenshots/` - Screenshots showing product features for the setup page or app guide.

---

## Logo Guidelines

- **Primary Logo**: Use dark mode versions wherever possible to align with IntelliSphere's rich aesthetic.
- **Aspect Ratio**: Standard circular icon mark (1:1 aspect ratio) and horizontal layout wordmark.
